# Rural Hospital Management System

## About the Project
The **Rural Hospital Management System** is a web-based application designed to simplify healthcare management in rural communities. It helps manage patient registration, doctor records, medical camps, and essential hospital activities efficiently.

## Features
- **Patient Management:** Register and manage patient records.
- **Doctor Management:** Add and manage doctor information.
- **Medical Camp Management:** Register and organize medical camps.
- **Record Management:** Maintain essential hospital information.
- **User-Friendly Interface:** Simplify daily hospital operations.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Objectives
- Improve hospital administrative efficiency.
- Simplify patient and doctor registration.
- Support medical camp organization.
- Promote better healthcare management in rural areas.

## Installation
1. Clone or download this repository.
2. Install and start XAMPP.
3. Place the project folder inside the `htdocs` directory.
4. Create a MySQL database using phpMyAdmin.
5. Import the project's SQL file, if provided.
6. Configure the database connection in the project.
7. Open your browser and visit `http://localhost/project-folder`.
